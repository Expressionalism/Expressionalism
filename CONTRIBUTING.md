# Contributing to Expressionalism

The work is provisional. You can accept it, refine it, take a piece, or set it down.

A sentence in Volume 1 or the Framework is as real a contribution as a change to the script.

## How to contribute

1. Fork the repository.
2. Create a branch.
3. Make the change.
4. If you touched the script, run it locally on one short input.
5. Open a pull request and say what you changed.

Questions can be issues. You do not have to know Git well. An issue that names a sentence and what is wrong with it is enough.

## What helps

- Fixes that make a file match another file in the corpus
- Examples run on ordinary things (a cup, a sum, a claim)
- Clearer wording in Volume 1 or the Framework
- Script fixes that do not quietly change what a number means

## What to leave alone unless you say so

- The license files
- The meaning of leftover, unlisted, and rim
- Treating the Secondary Coherence Score as the meaning of the thing
